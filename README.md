# Study OS — تطبيق إدارة الدراسة (Android / Java)

تطبيق يعمل بدون إنترنت: لوحة تحكم، مهام، تتبّع دراسة، Pomodoro، أهداف ومشاريع،
عادات، ملاحظات، لغات وبطاقات حفظ (Flashcards)، إحصائيات، بحث، وإعدادات (وضع داكن/فاتح، نسخ احتياطي).

## كيف تحصل على ملف APK (بدون أي برمجة)

1. أنشئ حسابًا مجانيًا على https://github.com (إن لم يكن لديك).
2. اضغط **New repository** وسمّه `StudyOS` ثم **Create repository**.
3. فك ضغط ملف المشروع على جهازك.
4. في صفحة المستودع اضغط **uploading an existing file**، ثم اسحب **كل محتويات** المجلد المفكوك
   (بما فيها المجلد المخفي `.github`) وأفلتها في الصفحة، ثم اضغط **Commit changes**.
   - إذا لم تظهر `.github` (مثلًا في macOS) فأنشئ الملف يدويًا: **Add file ← Create new file**،
     اكتب الاسم `.github/workflows/build-apk.yml` والصق محتوى الملف نفسه من المشروع، ثم Commit.
5. افتح تبويب **Actions**. سيبدأ البناء تلقائيًا (حوالي 5–10 دقائق).
   إن لم يبدأ: اختر **Build Study OS APK** ← **Run workflow**.
6. بعد أن يصبح الشريط أخضر، افتح التشغيل ونزّل **StudyOS-apk** من قسم **Artifacts**.
7. فك ضغط الملف المنزَّل، وانقل `app-release.apk` إلى هاتفك وثبّته
   (فعّل «السماح بالتثبيت من مصادر غير معروفة» عند الطلب).

إذا فشل البناء (علامة ✗ حمراء): افتح الخطوة الفاشلة وانسخ آخر أسطر الخطأ وأرسلها لي لأصلحها.

## ملاحظات
- الـ APK موقّع بمفتاح debug لكي يُثبَّت مباشرة؛ مناسب للاستخدام الشخصي.
- النسخ الاحتياطي: Settings ← Export / Import (ملف قاعدة البيانات كاملًا).
- لإبقاء مؤقت Pomodoro دقيقًا، اترك التطبيق مفتوحًا أو في التطبيقات الأخيرة.
